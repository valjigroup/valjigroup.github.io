# Valji Group website

Production-oriented static website for Valji & Brothers / Valji Group.

## Current functionality

- Responsive one-page company website
- Accessible mobile navigation and keyboard states
- WhatsApp enquiry helper with native browser validation
- Organization structured data, Open Graph metadata and canonical URL
- Sitemap, robots policy, web manifest and custom 404 page
- GitHub Pages deployment workflow

## Local development

No build step or package installation is required. Open `index.html` directly or serve the repository root with any static HTTP server.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` packages only the production files into `_site` and publishes them through GitHub Pages. In the GitHub repository, set **Settings → Pages → Source** to **GitHub Actions**.
